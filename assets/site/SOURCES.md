# Growza home-page artwork

The photographs behind the hero, the ten category tiles, the "Why a price is
on the card" panel and the closing call to action. All were taken from Pexels
pages marked "Free to use", resized and re-encoded for the web, and kept in
this folder so the home page never depends on a third-party server at runtime.

They are deliberately a different set from `assets/web-services/`: those
belong to individual service listings, and the same photograph appearing in
two places on one screen reads as a mistake rather than as a theme.
